# Vetri Thiran / AI WeatherWise – Phase-Wise Project

This package reorganizes the submitted `vetri-thiran-payirchi-thittam` backend into an 8-phase AI/ML/Gen-AI project structure.

## Project Focus
AI WeatherWise provides:
- JWT authentication
- Favorite location management
- Current weather retrieval
- Gemini AI weather summaries
- Gemini AI weather recommendations
- Mock/rule-based fallback behavior

## Where is the code?
The complete original source is available in:
- `5. Project Development/Source Code/`
- `Project Source Code/`

## Run
```bash
cd "Project Source Code/Backend"
npm install
npm run dev
```

Create a `.env` file with MongoDB, JWT, OpenWeatherMap and Gemini configuration as described in Phase 2.
