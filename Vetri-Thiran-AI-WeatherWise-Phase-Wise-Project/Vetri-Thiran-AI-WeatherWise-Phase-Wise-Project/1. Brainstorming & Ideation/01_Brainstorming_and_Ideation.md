# Phase 1 – Brainstorming & Ideation

## Project Title
**AI WeatherWise – AI-Powered Weather and Location Assistant**

## Problem
Users need weather information, favorite-location management, and practical interpretation of weather conditions. Raw weather metrics alone may not be easy to understand.

## Proposed Solution
Build a RESTful backend that:
- Provides current weather information for a city
- Allows registered users to save favorite locations
- Uses Gemini AI to create concise weather summaries
- Provides practical weather recommendations

## Target Users
- General users who want weather information
- Users who monitor multiple favorite cities

## Core Features
1. User registration and login
2. JWT authentication
3. User profile retrieval
4. Favorite location CRUD
5. Current weather API
6. Gemini AI weather summary
7. Gemini AI weather recommendation
8. Mock fallbacks when external API keys are unavailable

## Technology Idea
Node.js, Express.js, MongoDB/Mongoose, JWT, bcryptjs, OpenWeatherMap and Google Gemini.
